# 研究约定 Conventions

量化研究中最昂贵的错误往往不是代码 bug，而是**方法论错误**——它们不会报错，
只会让回测结果好看得不合理。本文档记录本项目的硬性约定与检查清单。

---

## 一、数据与可复现

- 原始数据与凭据**不提交**版本控制。
- 每次实验必须记录：数据来源、样本区间、时区、复权方式、缺失值处理（见 [DATA.md](DATA.md)）。
- 可复用逻辑放 `src/`，探索过程放 `notebooks/`。判断标准是「是否会被第二次使用」。
- 每次实验记录参数、代码版本与结论。路线图 P6 会将这一步自动化。
- 若某段代码只跑一次且结论已归档，留在 `notebooks/` 即可，不必强行抽象进 `src/`。

## 二、回测必须显式声明的假设

回测结果只对「声明过的假设」成立。以下四项缺一不可：

| 假设 | 说明 | 当前配置 |
| --- | --- | --- |
| 手续费 | 按成交金额计，双边 | `commission_bps: 5` |
| 滑点 | 实际成交价与理想价的偏离，买入更贵、卖出更便宜 | `slippage_bps: 2` |
| 成交价 | 用什么价格撮合 | 默认 `close`（前一 bar 收盘），可配 `open` / `vwap` |
| 初始资金 | 影响仓位取整与容量 | `initial_cash: 100000` |

> **重要**：这些参数由 `BacktestConfig.from_settings()` 读入引擎，`result.config.to_dict()`
> 会完整回显当次运行的全部假设。任何对外分享的结果都必须附上这份配置。

## 三、偏差防护

### 前视偏差（Look-ahead Bias）

使用了「当时还不可得」的信息。

- 用收盘价算出的信号，**只能在下一期成交**。务必 `signal.shift(1)`。
- 用全样本统计量（均值、标准差、分位数）做标准化，会把未来信息泄漏进历史。
  滚动窗口计算才是正确做法。
- 财报类数据必须按**实际公告日**而非报告期对齐。

项目约定：信号函数返回**未滞后**的原始值，滞后统一由回测引擎执行（已实现，`run_backtest` 内部 `shift(lag)`）。

### 幸存者偏差（Survivorship Bias）

只测试了「活下来」的标的。

- 回测的标的池必须是**当时**的成分股，而非今天的成分股。
- 已退市、被剔除的标的必须包含在样本内。

### 过拟合（Overfitting）

参数在历史数据上被调到最优，但在样本外失效。

- 划分样本内 / 样本外，样本外只使用一次。
- 记录参数敏感性：最优参数周围若存在大片稳定区域，结果更可信；孤立的尖峰通常意味着过拟合。
- 与随机信号、买入持有做对照。若策略无法显著优于随机对照，说明没有真实 edge。

## 四、上线前检查清单

任何策略在进入纸面交易前，逐条确认：

- [ ] 信号已滞后一期，且有用测试断言
- [ ] 手续费、滑点已计入且取值保守
- [ ] 样本区间覆盖完整牛熊周期，而非单一趋势段
- [ ] 标的池无幸存者偏差
- [ ] 已完成样本外验证或 walk-forward
- [ ] 换手率在可承受范围内（成本会吃掉高频交易的收益）
- [ ] 已报告「无换手控制」与「带 `buffer` / 最小成交额」两种口径，确认结论不依赖日常调仓噪音
- [ ] 单标的 / 杠杆 / 净敞口约束（`PortfolioPolicy`）已声明，或其缺失已被显式论证
- [ ] 参数敏感性已检查，不存在孤立最优尖峰
- [ ] 实验参数、数据区间、代码版本已归档

## 五、风险声明

- 本工作区**仅用于离线研究与模拟**，没有实盘交易连接。
- 任何信号与指标仅供方法学研究，**不构成投资建议**。
- 历史回测结果不代表未来表现。
