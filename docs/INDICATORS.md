# 技术指标 Indicators

**这份文档给实现者看：公式、参数、以及那些写错了不会报错、只会让结果悄悄偏掉的细节。**

它不是买卖指南。指标描述的是价格**已经**做了什么，不预测它接下来要做什么；文档里
出现的所有"超买""金叉"都只是约定俗成的叫法，不代表任何预测能力。

项目目前只用了四个截面因子（动量、均线距离、波动率倒数、流动性，见
`src/quant_research/scoring/factors.py`）。这份文档记录的是"如果要加，该怎么算"，
以及"为什么不能直接把指标当分数用"（最后一节）。

---

## 通用约定

- **输入是一张宽表**：`index=DatetimeIndex(date)`，`columns=标的代码`，一列一只标的。
  所有函数都接受宽表、返回宽表，索引与列都不动。
- **全部向量化**：`pandas` 的 `rolling` / `ewm` / `cumsum`，不逐行循环。全市场几千列，
  双层 `iterrows` 会把一次计算变成几分钟（`describe_panel` 已经踩过这个坑）。
- **每个值只看过去**：指标用当日及以前的数据；信号次日才能执行。回测与选股的成交假设
  必须一致，否则回测是幻觉。
- **不引入 TA-Lib**：编译依赖带来的麻烦大于收益，pandas 足够表达这些公式。
- **统一前复权（qfq）**：不同源的前复权基准不同，跨源混用会让任何跨期比较失去意义。

## 先说五个贯穿所有指标的坑

后面每个指标只写它特有的坑，这几条不再重复。

### 1. `ewm` 的默认值不是行情软件里的那个 EMA

`pandas` 的 `ewm(span=n)` 默认 `adjust=True`，前几根用加权平均修正，而 TA-Lib、
通达信、同花顺用的是递推式 `E_t = α·x_t + (1-α)·E_{t-1}`。两者在前几十根上肉眼可见地
不同（实测同一序列 `span=3`）：

```text
adjust=True  : 10.0000  10.6667  11.4286  11.2000  12.1290
adjust=False : 10.0000  10.5000  11.2500  11.1250  12.0625
```

想和行情软件对上，必须 `adjust=False`。

### 2. `ewm` 第一根 K 线就出值

`rolling(n)` 前 `n-1` 个是 `NaN`，但 `ewm(adjust=False)` 的第一个值就是它自己——
于是第 1 天就有一个"14 日 RSI"，而它其实只用了 1 根 K 线。

```text
rolling(5).mean()          : nan  nan  nan  nan  100.34  100.43
ewm(span=5, adjust=False)  : 100.13  ...（第一根就有值）
```

**所以每个 `ewm` 都要显式给 `min_periods`**，否则指标的"预热期"是假的，而它在回测里
表现为开头几十根异常的进出场信号——很难查，因为没有任何一行代码是错的。

### 3. 标准差的 `ddof`：布林带用总体，不是样本

`pandas` 的 `.std()` 默认 `ddof=1`（样本标准差），布林带的公式用的是总体标准差
`ddof=0`。`n=20` 时两者相差 **2.60%**（实测 3.2324 vs 3.3163），带宽整体偏宽，
突破信号会系统性来得更晚、更少。

### 4. 停牌、新股与一字板

- 停牌日没有行情 → 序列里是 `NaN` → `rolling` 窗口里有 `NaN` 就整段变 `NaN`。
  按"缺失策略"处理（本项目用 `missing_policy="keep"`），指标端用 `min_periods` 兜住。
- 新股上市不足 `n` 天 → 指标为 `NaN`，不是 0。选股时这条由 `short_history` 统计，
  不要让它掉进 `no_score`（那是另一回事）。
- 一字板（`open == high == low` 且近涨停）会让 KDJ、威廉%R 这类"区间位置"指标的分母
  为 0 → 除零。指标照算没问题，名单要剔除（选股层已经做）。

### 5. 指标是时序的，因子是截面的

RSI=70 对一只常年高波动的票和对一只大盘银行股，含义完全不同。**把指标的绝对值直接
拿去横向排序是错的**——必须先逐日标准化（`zscore_by_day`），这也是 `scoring` 里
逐日 z-score 而非全样本标准化的原因。详见最后一节。

## 趋势类

### MA / EMA

最简单，也最容易被用错：均线是滞后量，它说的是过去，不是未来。

```text
MA(n)  = 最近 n 根收盘价的均值
EMA(n) : E_t = 2/(n+1) · C_t + (1 - 2/(n+1)) · E_{t-1}
```

```python
ma = close.rolling(n).mean()
ema = close.ewm(span=n, adjust=False, min_periods=n).mean()
```

**常用参数**：5 / 10 / 20 / 60 / 120 / 250。
**坑**：`min_periods` 见上文；另外均线的"金叉死叉"在震荡市里会反复打脸，交易次数
比收益更值得先看一眼。

### MACD（12, 26, 9）

```text
DIF  = EMA(12) - EMA(26)
DEA  = EMA(DIF, 9)              # 信号线
柱   = 2 × (DIF - DEA)          # 国内软件画 2 倍；国外文献通常是 1 倍
```

```python
dif = (
    close.ewm(span=12, adjust=False, min_periods=12).mean()
    - close.ewm(span=26, adjust=False, min_periods=26).mean()
)
dea = dif.ewm(span=9, adjust=False, min_periods=9).mean()
hist = 2 * (dif - dea)
```

**坑**：
- 柱子 1 倍还是 2 倍，决定了"零轴附近"的视觉尺度，也决定了很多网上抄来的阈值能不能
  直接用。写文档时注明用哪一种，别让读者猜。
- DIF 依赖 EMA(26)，前 26 根是 `NaN`——MACD 的预热期比多数人以为的长。

### DMI / ADX

衡量趋势的**强度**，不判断方向。

```text
+DM = 当日最高价高于昨高的部分（为负记 0），-DM 同理
TR  = max(H-L, |H-昨收|, |L-昨收|)
+DI = 100 × Wilder平滑(+DM) / Wilder平滑(TR)
-DI = 100 × Wilder平滑(-DM) / Wilder平滑(TR)
DX  = 100 × |+DI - -DI| / (+DI + -DI)
ADX = DX 的 Wilder 平滑（通常再取 14）
```

**坑**：`+DI + -DI = 0` 时分母为 0（全天无波动，一字板）→ 需保护；
ADX 本身滞后，它上升只说明"趋势正在变强"，不说方向。

## 震荡类

### RSI（14）

```text
delta = C_t - C_{t-1}
平均涨幅 = 上涨幅度的 Wilder 平滑（alpha = 1/n）
平均跌幅 = 下跌幅度（取绝对值）的 Wilder 平滑
RS  = 平均涨幅 / 平均跌幅
RSI = 100 - 100 / (1 + RS)
```

```python
delta = close.diff()
gain = delta.clip(lower=0)
loss = (-delta).clip(lower=0)
avg_gain = gain.ewm(alpha=1 / n, adjust=False, min_periods=n).mean()
avg_loss = loss.ewm(alpha=1 / n, adjust=False, min_periods=n).mean()
rsi = 100 - 100 / (1 + avg_gain / avg_loss)
```

**坑**：
- **Wilder 平滑 vs 简单均值是两种 RSI**（Cutler's RSI）。数值不同，阈值不同。
  上面是 Wilder 版（也是 TA-Lib 与国内软件的默认）。
- **平均跌幅为 0 → 除零，RSI 应为 100**，不是 `inf`。同理平均涨幅为 0 时 RSI = 0。
  `pandas` 不会替你处理，回测里会污染后续所有计算。
- RSI 在强趋势里会长期"超买"——把它当反转信号用，是它最常见的误用。

### KDJ（9, 3, 3）

```text
RSV = (C - L9) / (H9 - L9) × 100        # H9/L9 = 9 日内最高/最低
K   = 2/3 × 前K + 1/3 × RSV             # 初值 50
D   = 2/3 × 前D + 1/3 × K               # 初值 50
J   = 3K - 2D
```

**坑**：
- K 和 D 是**递推**的，且**初值是 50 而不是第一个 RSV**。
  `ewm(alpha=1/3, adjust=False)` 的第一项是 RSV 本身，与"初值 50"不同——要么循环，
  要么把首值改掉。这是 KDJ 与 RSI 在写法上最容易出错的差别。
- `H9 == L9`（一字板、停牌后复牌）→ 分母为 0，RSV 未定义。
- J 值可以超出 0~100，这不是 bug。

### 威廉 %R（14）

```text
%R = (H_n - C) / (H_n - L_n) × (-100)     # 取值 -100（最低）到 0（最高）
```

**用途**：与 KDJ 的 RSV 同源，只是坐标相反、没有平滑。
**坑**：区间长度为 0 时同样除零；不同资料对符号约定不一致，落笔时写明区间是
`-100~0` 还是 `0~100`。

### CCI（14）

```text
TP = (H + L + C) / 3
MA = TP 的 n 日均值
MD = |TP - MA| 的 n 日均值            # 平均绝对偏差，不是标准差
CCI = (TP - MA) / (0.015 × MD)
```

**坑**：`MD` 是**平均绝对偏差**而非标准差，写错后 CCI 的尺度整体不对，而形状看起来
"很像"，极难发现；`0.015` 这个系数是为了让约 70% 的值落在 ±100 内，是约定值。

## 波动率类

### ATR（14）

```text
TR  = max(H - L, |H - 昨收|, |L - 昨收|)
ATR = TR 的 Wilder 平滑（alpha = 1/n）
```

```python
prev = close.shift(1)
tr = pd.concat([high - low, (high - prev).abs(), (low - prev).abs()], axis=1).max(axis=1)
atr = tr.ewm(alpha=1 / n, adjust=False, min_periods=n).mean()
```

**用途**：止损距离、`inverse_volatility` 权重的输入。它比"收益率的滚动标准差"好，因为
用到了最高最低价，对跳空也敏感。
**坑**：`high`/`low` 缺失时 `concat` 会给出全 `NaN` 的一行——需要 `min_periods` 与
缺失策略配合。

### 历史波动率（年化）

```text
日收益 = close.pct_change()
已实现波动率 = 日收益.rolling(n).std(ddof=1) × sqrt(252)
```

**坑**：这里用 `ddof=1`（样本）是对的——它是在**估计**总体波动率，与布林带描述
"这一段价格的离散程度"（`ddof=0`）不是同一件事。年化系数 252 是 A 股一年约 242~244
个交易日的惯例近似，跨市场比较时统一即可。

### 布林带 BOLL（20, 2）

```text
中轨 = MA(20)
上轨 = 中轨 + k × σ          # σ 用总体标准差 ddof=0，k 通常取 2
下轨 = 中轨 - k × σ
带宽 = (上轨 - 下轨) / 中轨   # 衡量"挤不挤"，比位置更有信息量
```

```python
mid = close.rolling(n).mean()
spread = close.rolling(n).std(ddof=0)  # 不是 pandas 默认的 ddof=1
upper, lower = mid + k * spread, mid - k * spread
```

**坑**：`ddof`（见上文，2.60% 的带宽差）；带宽收窄只说明波动变小，不说方向。

## 成交量类

### OBV

```text
若 C > 昨收：OBV += 成交量
若 C < 昨收：OBV -= 成交量
其余：不变
```

```python
direction = close.diff().fillna(0.0)
obv = (volume * direction.map(lambda v: 0.0 if v == 0 else (1.0 if v > 0 else -1.0))).cumsum()
```

**坑**：OBV 是**累计量**，绝对值取决于起点，只能看趋势、不能横向比较；除权除息日的
量价关系会失真（前复权改的是价格，成交量不动）。

### VWAP（成交均价）

```text
VWAP = 成交额 / 成交量
```

**坑（单位）**：本项目 `volume` 存的是**手**，`amount` 是**元**，所以
`VWAP = amount / (volume × 100)`。少乘这个 100，均价会贵 100 倍，而曲线形状完全
正常——这是单位错误里最难发现的一类。各 provider 原始单位不同（BaoStock 报股、
AKShare 报手），换算已在 provider 层统一，新增数据源时别再改回去。

### 换手率与流动性

```text
换手率 = 成交量 / 流通股本
```

流通股本不在日线里（需要基本面数据），所以选股层用**成交额的滚动均值**做流动性过滤
（`min_amount`）——这是可得数据里的合理替代。`scoring/factors.py` 的流动性因子与
`screen(min_amount=...)` 已经是这么做的。

## 指标 ≠ 因子：为什么不能直接拿 RSI 排序

这是把上面的指标接进选股时最容易犯的错，也正是 `scoring` 层存在的原因。

| | 技术指标（RSI / MACD / BOLL） | 截面因子（`scoring/factors.py`） |
| --- | --- | --- |
| 方向 | **时序**：一只票沿着时间算 | **截面**：同一天所有票横向比 |
| 绝对值 | 跨标的不可比（各自的波动性格不同） | 逐日 z-score 后可比 |
| 典型误用 | 把 RSI=70 当"比 RSI=60 更强" | —— |

所以正确的接法是：**指标先算，再逐日标准化，再进组合**。而且逐日标准化不能换成
"全样本一次性标准化"——后者会让周一的分数依赖全年走势，是前视偏差。

`scoring` 已经有四个因子（动量、均线距离、波动率倒数、流动性）。要加 RSI 或 MACD
作因子时：

1. 在 `scoring/factors.py` 里加一个向量化函数，输入 `PricePanel`、输出宽表，
   每个值只看过去；
2. 交给 `combine()` 做逐日 z-score 与加权；
3. 补两条测试：手算小样本核对、以及**防前视自检**（截断历史重算，同一天的结果必须
   完全一致）——这条自检是整个 `scoring` 的验收标准，别跳过。

## 实现约定（落地时照此办理）

- **签名统一**：`def xxx(panel, *, n=14, **kwargs) -> pd.DataFrame`，宽表进、宽表出，
  不改索引、不改列。
- **参数写默认值**，与行情软件惯例一致（MACD 12/26/9、RSI 14、BOLL 20/2、KDJ 9/3/3）。
- **`min_periods` 必须显式给**，尤其是所有 `ewm`。
- **除零全部显式处理**：RSI 的单边行情、KDJ/威廉的一字板、ADX 的无波动。
- **不要 `dropna()` 了事**：那会让每只标的的可比起点不同，回测的样本期悄悄变短。
- **测试三件套**：手算小样本、防前视自检、边界（`NaN`、除零、不足 `n` 根）。

## 实现与配置

代码在 `src/quant_research/indicators.py`（公式与坑），入口是 `indicators_cli.py`。

```bash
quant-indicators --provider baostock --symbols 600519.SH,000001.SZ
quant-indicators --provider baostock --all          # 全市场，慢
quant-indicators --from-cache                       # 用已缓存的面板，不联网
quant-indicators --from-cache --format csv           # 换存储格式
```

**参数全部在 `config/settings.yaml` 的 `indicators` 段**，命令行只决定数据从哪来、存到哪去。
周期这类东西属于配置，不属于 shell 历史。

| 键 | 默认 | 含义 |
| --- | --- | --- |
| `ma_periods` | `[5, 10, 20, 60]` | 均线组，可写多个 |
| `ema_periods` | `[12, 26]` | 指数均线组 |
| `macd_fast` / `macd_slow` / `macd_signal` | `12` / `26` / `9` | MACD 三参数 |
| `rsi_period` | `14` | Wilder 平滑 |
| `boll_period` / `boll_std` | `20` / `2.0` | 带宽倍数 |
| `kdj_period` / `kdj_smooth` | `9` / `3` | K、D 初值 50 |
| `atr_period` | `14` | TR 的 Wilder 平滑 |
| `williams_period` / `cci_period` / `adx_period` | `14` | |
| `volatility_period` | `20` | 年化 252 |
| `output_directory` | `data/indicators` | 落盘位置 |
| `format` | `parquet` | `parquet` 或 `csv` |

非法值直接拒绝启动（`rsi_period: 0`、`boll_std: 0`、未知键），不会让 `ewm` 拿到零窗口。

**落盘结构**：

```text
data/indicators/baostock_qfq/
    ma_20.parquet  rsi_14.parquet  macd_hist.parquet  …
    meta.json          # 参数、生成时间、行数、标的数、字段清单
```

两处刻意设计：

- **字段名带周期**（`rsi_21` 而不是 `rsi`）：改配置后文件名跟着变，旧文件不会被当成新口径读。
- **`meta.json` 记录 `params`**：`rsi_14.parquet` 和 `rsi_21.parquet` 在磁盘上长得一模一样，
  唯一能区分的是这个文件。

读回：

```python
from quant_research.indicators import load_bundle

bundle = load_bundle("data/indicators", "baostock", "qfq")
bundle.frames["rsi_14"]  # 宽表：索引日期，列是标的
bundle.params.rsi_period  # 14，来自 meta 而不是猜测
```

**能算多少取决于数据有多少**（静默降级，不报错）：

| 面板有的字段 | 可算出的指标 |
| --- | --- |
| `close` | MA、EMA、MACD、RSI、BOLL、已实现波动率 |
| 加上 `high` / `low` | KDJ、ATR、威廉 %R、CCI、DMI/ADX |
| 加上 `volume` / `amount` | OBV、VWAP |

一份只有收盘价的 CSV 也能用——少算几类，而不是拒绝计算。

## 界面展示

原则一句话：**指标是描述，不是判断**。界面只回答「现在是什么状态」，不回答「该不该买」。

每一条指标的展示规格固定为六个元素，全部来自代码里的 `INDICATOR_CATALOG`
（`indicators.catalog()` 可直接输出成 JSON 供接口使用）：

| 元素 | 示例（RSI） |
| --- | --- |
| 名称 | `RSI(14)` —— **标签必须带周期**，光写「RSI」说明不了什么 |
| 单位 / 量纲 | 0–100 |
| 常见区间 | 20–80 |
| 一句话说明 | 一段时间内上涨幅度占涨跌总幅度的比例 |
| 建议读法 | 当作温度计而不是开关：>80 说明近期几乎只涨 |
| 误读提醒 | 强趋势里会长期钝化在超买区，用它做反转信号是最常见的误用 |

说明文字**不要硬编码在前端**。代码改了口径而界面还念着旧词，是最难发现的一类不一致；
统一从 `catalog()` 取，路径只有一条。

**可直接用的文案示例**：

```text
RSI(14)      56.3      0–100 · 20–80 常见     近期上涨力量略占优
BOLL 带宽    0.054     —                       波动在压缩，方向未知
ATR(14)      0.42 元   约股价 3.6%            定止损距离用
VWAP         11.55     收盘 11.64 在其上方     当日买方占优
```

**界面上不应该出现的五样东西**：

1. **「买入 / 卖出 / 持有」标签**——指标不含仓位、成本与风险预算，给它贴操作标签是越界。
2. **「预期收益」**——台账里三次回放的平均超额是 −0.0004，写上去等于把噪声包装成承诺。
3. **不标日期的数值**——盘前打开时它讲的是昨天。名单和指标都要写「数据截至 X」。
4. **不带参数的指标名**——「RSI」是 14 还是 6？标签里必须带周期，`rsi_14` 这种键名同理。
5. **跨标的的绝对值对比**——RSI=70 对高波动票和大盘股不是一回事，见最后一节。

颜色只在**有明确惯例阈值**的地方使用（RSI 的 20/80、CCI 的 ±100），其余保持中性。
不要建立「越红越要买」这类映射——那是在给数值编故事。

**已落地**：工作台的「指标」视图（`GET /api/indicators`、`GET /api/indicators/{symbol}`）
就是照这一节做的——表里每个数字都带名称、量纲、常见区间和建议读法，说明文字直接取自
`indicators.catalog()`，不再另写一份。它还多守了一条自己的规矩：**价格量纲的指标不显示
截面区间**。MA5 那行原本显示 `3.28 ~ 1356.54`，那不是行情，只是不同价位的票被放在一起
求了个范围；留空比给一个看起来像信息的数字好。

**曲线**（`GET /api/indicators/{symbol}/series`）按面板分开画：价格与布林带、RSI、MACD、
KDJ 各一张。不合并是有原因的——RSI 在 0–100、价格在几元到上千元，共用一张图就必须双
纵轴，而双纵轴上的「交叉」几乎总是巧合。三处细节：

| 细节 | 为什么 |
| --- | --- |
| 预热期的 `null` **断线** | 把 `NaN` 当 0 画，RSI 开头会出现一段并不存在的暴跌 |
| MACD 柱画成**柱**而不是线 | 要看的是哪一侧，不是斜率 |
| RSI/KDJ 画出 **20/80 参考线** | 那是读者记得的阈值；只在数据本身越过时才显示，等于没画 |

面板按**指标族**取字段（`rsi` 而不是 `rsi_14`）：把 `rsi_period` 改成 21，曲线跟着换一条，
而不是整张图空掉。

## 建议使用方式

### 一、当状态描述用（最稳）

| 维度 | 看什么 | 别指望它 |
| --- | --- | --- |
| 趋势 | 价格 vs MA20/MA60、ADX 强弱 | 预测顶底 |
| 波动 | ATR、已实现波动率、BOLL 带宽 | 说出方向 |
| 位置 | RSI、威廉 %R、KDJ、CCI | 保证反转 |
| 量能 | OBV 趋势、收盘 vs VWAP | 判断主力意图 |

一次看 **2–4 个不同维度**的指标，比堆十个同类震荡指标有用得多——同类的彼此高度相关，
堆在一起只是给同一个判断反复加权。

### 二、互相验证，而不是互相替代

- **趋势 + 位置**：ADX 高、ATR 在扩大时，RSI 的「超买」不构成反转信号——趋势正在走强，
  钝化是常态。
- **位置 + 量能**：%R 在低位、OBV 同步走低，说明卖压仍在，不急于抄底。
- **只有同向时才降低犹豫**：两个信号同向不等于可以下单，它只说明「描述一致」；
  仓位、成本、风险预算仍然要单独决定。

### 三、当因子的原料（本项目的走法）

指标是时序的，直接排序是错的，必须走这条链：

```text
指标（时序） → zscore_by_day（逐日截面标准化） → combine（加权） → screen（排序、过滤、归档）
```

`scoring/factors.py` 已有四个因子（动量、均线距离、波动率倒数、流动性）。要加新因子：

1. 因子函数输入 `PricePanel`、输出宽表，每个值只看过去；
2. 交给 `combine()` 逐日标准化与加权；
3. 补两条测试：手算小样本 + **防前视自检**（截断历史重算，重叠日期必须逐值一致）。

### 四、四条常见误区

| 误区 | 为什么错 |
| --- | --- |
| 「RSI > 70 就该卖」 | 强趋势里 RSI 会长期停在 70 以上，卖早了整段行情都错过 |
| 「金叉买、死叉卖」 | 震荡市里交易次数暴增，成本先吃掉大部分名义收益 |
| 「指标越多越准」 | 同类指标高度相关，等价于给同一个判断重复加权 |
| 「把指标值当分数排序」 | 绝对值跨标的不可比：波动率不同的票，同样的 RSI 含义不同 |

## 验证与边界

- **34 条测试**：公式手算核对（EMA/RSI/KDJ/ATR/BOLL/TR/OBV/VWAP 各有独立手算案例）、
  防前视（截断历史重算逐值一致）、除零与 NaN 边界（单边行情、完全无波动、一字板、零成交量）、
  落盘往返、目录与计算字段一一对应。
- **真实数据实测**（baostock，30 只 × 683 个交易日，2024-01-02 → 2026-10-30）：
  26 个指标；RSI 落在 8.5–97.0、KDJ-K 2.6–97.3、ADX 6.3–83.9、带宽恒为正、ATR 恒为正；
  VWAP 11.55 与收盘 11.64 同量级——单位没有写错。
- **没有与第三方指标库逐值对拍**。公式按本文档手算，未跟 TA-Lib 做浮点级比对。
  若需要与某个行情软件逐值一致，得另做一次对拍（尤其 MACD 柱的 1 倍/2 倍、
  KDJ 初值、EMA 前几十根）。
- 指标不含资金流（除 OBV/VWAP）、不含基本面，也**不含任何预测成分**。
