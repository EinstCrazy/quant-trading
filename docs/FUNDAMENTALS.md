# 财报与财务风险

> 这一页回答：这家公司有没有可能在一年内出事，而价格完全没反映出来？

## 为什么不看价格

`scoring/` 的七个因子全部来自价格：动量、均线、波动率、布林位置。它们能告诉你
**别人在买什么**，不能告诉你**这家公司在做什么**。当一家公司靠续贷维持经营、
利润是应收账款堆出来的、或者已经在亏损，K 线在爆掉之前往往一样漂亮。

所以这一层不是又一个因子，而是一道**否决权**：先排除明显有问题的，再在剩下的里面排序。

## 六面红旗

| 红旗 | 触发 | 权重 | 为什么 |
| --- | --- | --- | --- |
| 亏损 | 净利润 < 0 | 30 | 没有可估的市盈率，也最有动机靠一次性收益修饰报表 |
| 资产负债率过高 | > 70% | 25 | 利率与再融资窗口的微小变化能吞掉一年利润 |
| 利润不含现金 | 经营现金流/净利润 < 0.3 | 20 | 利润是账面数字，现金才是到手的；长期偏低通常来自应收账款堆积 |
| 短期偿债吃紧 | 流动比率 < 1 | 15 | 流动负债超过流动资产，短期要靠续贷或变卖存货 |
| 净利润大幅下滑 | 同比 < −30% | 15 | 单期腰斩先分清是一次性计提还是需求真的走了，前者会修复，后者不会 |
| 利息保障倍数过低 | EBIT/利息 < 1.5 | 10 | 经营利润快盖不住利息，一次加息就能击穿 |

分数是权重之和（上限 100），≥ 50 为**高**、≥ 25 为**中**、否则**低**。
每一面旗都带数值与阈值出现在输出里，因为"高风险"三个字不能作为决策依据。

## 三件比规则更麻烦的事

### 1. 数据本身会错

BaoStock 的 `liabilityToAsset` 出现过**一百倍**的错误：2025Q2 的茅台报 `0.0015`，
而同一行的 `assetToEquity = 1.173` 反推出 `0.1475`。

```python
assetToEquity = 总资产 / 净资产   →   负债率 = 1 − 1 / assetToEquity
```

权益乘数是两个大数的比值，不容易错位；单一预先算好的比例容易。所以两者相差超过
10 个百分点时，**以反推值为准**。这不是洁癖：0.0015 的负债率会让一家高杠杆公司
看起来像没有负债。

### 2. 银行的负债不是风险

兴业银行 2026Q3 的负债率是 **91.3%**。按上面的规则，它会被判成高杠杆——但存款
是银行的原料，不是它的麻烦。判错的代价是整条银行、保险、券商板块被无声地排除出
选股名单，而使用者只会以为"今天没选出好票"。

没有行业字段，只能从财报本身认：**毛利率缺失**（金融企业没有营业成本概念）+
**负债率 > 85%**，两者同时成立才按金融口径处理。此时杠杆与流动比率两面旗**不计分**，
但仍然列在输出的 `waived`（豁免）里——它不是"规则不适用所以删掉"，而是"规则触发了，
但尺子不是为它做的"。

两个信号必须同时成立：只看负债率会误伤陷入困境的制造业，只看毛利率缺失则可能只是
数据缺了。

### 3. 财报有滞后，而且各标的不是同一天

2026Q3 的财报在 10 月 24 日到 31 日之间陆续披露。用"最新一期"去评估 6 月的选股，
等于用 8 月才知道的事情解释 6 月的决定。

所以每一行都带 `pubDate`，取数时只接受 `pubDate <= as_of` 的报告：

```python
panel.latest("600519.SH", as_of="2026-09-01")  # → 2026Q2，不是 Q3
```

`quant-screen --as-of 2026-06-01 --exclude-risky` 会一路对齐到那天为止已披露的口径。

## 实测（baostock，2026Q3）

```
symbol     level  score   负债率  流动比  现金/利润  净利同比  原因
601166.SH  低        20    91.3%       —      -5.38     -4.0%  利润不含现金；金融口径，不计 资产负债率过高
600887.SH  低        15    61.5%    0.59       1.79    -17.1%  短期偿债吃紧（流动比率 < 1.0）
000001.SZ  低         0    90.6%       —       7.23      2.2%  无红旗；金融口径，不计 资产负债率过高
600519.SH  低         0    11.9%    7.19       1.26     -0.3%  无红旗
```

三处读法：

- **兴业银行的现金/利润是 −5.38。** 银行的经营现金流包含存贷款变动，投放贷款越多
  现金流越负。这条规则对银行同样偏颇——它被留下，是因为存款流失确实是信号，
  只是解释完全不同。**这条没有豁免，是已知的粗糙。**
- **伊利流动比率 0.59。** 快消企业常年如此（预收款少、应付账款多），未必是危险信号，
  但配合 61.5% 的负债率，值得知道它靠什么周转。
- **茅台负债率 11.9%、流动比 7.19、现金/利润 1.26。** 干净。

四只全部落"低"，是因为样本里没有真正出问题的公司——**这张表的价值在排除，不在排名**。

## 怎么用

```bash
quant-fundamentals --provider baostock                       # 缓存里的标的
quant-fundamentals --provider baostock --symbols 600519.SH,601166.SH
quant-fundamentals --provider baostock --refresh             # 重拉最新季度
quant-fundamentals --provider baostock --as-of 2026-09-01   # 那天可知的口径
quant-fundamentals --provider baostock --min-level 中        # 只看值得担心的

quant-screen --provider baostock --exclude-risky            # 剔除高风险，再选股
quant-screen --provider baostock --exclude-risky 中         # 连中风险一起剔除
```

财报缓存落在 `data/fundamentals/baostock/reports.parquet`，按 `(symbol, period)` 一行。
增量拉取：已有的季度不会重拉，新传的标的会补。

## 边界

- **没有行业分类。** 阈值按非金融工业股标定，金融地产靠"毛利率缺失"这个启发式识别，
  不保证准。真正的修法是接行业字段，不是继续加启发式。
- **单季度口径。** `netProfit` 是累计值（Q3 是前三季度），不是单季。看同比可以，
  算单季环比不行。
- **只看财报，不看公告。** 商誉减值、诉讼、股权质押、审计意见变更都不在这里，
  而它们往往比比率更早预警。
- **被标红不等于要卖。** 一张排查清单的用途是把注意力引到该看的地方，
  不是替你做决定。没被标红的公司同样可能刚出事——这套规则只覆盖它能看到的六个面。
- **`未知` 不是通过。** 没有财报数据时，输出是"未知"，选股默认不会因此剔除它。
  拿不到数据时要不要买，是一个需要人回答的问题。
