回测验证

三条可编码战法（海龟 / 放量突破 / MA20 回踩）按日线 0/1 信号、等权持有、含成本回测；金字塔加仓、ATR 定仓、盘中触发不在编码范围——结果只回答「规则在本样本上的毛收益轮廓」，亏不代表战法错，赚也不代表照做就对
